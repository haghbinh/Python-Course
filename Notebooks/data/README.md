# Datasets

- `penguins.csv` — Palmer Penguins data (344 penguins, 3 species, Palmer Archipelago, Antarctica), collected by Dr. Kristen Gorman and the Palmer Station LTER. Released under CC0. Source: Horst AM, Hill AP, Gorman KB (2020), palmerpenguins R package; CSV taken from the `palmerpenguins` Python package (MIT).
- `bank_log.csv` — synthetic two-week ticket log of a bank branch for Project 2 (session 20); generated for this course, contains deliberate data errors.
- `air/` — synthetic one-year hourly air-quality data of four stations, daily weather and pollution-closure days for the final project (session 30); generated for this course, contains deliberate data errors.
