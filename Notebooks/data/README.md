# Datasets

- `penguins.csv` — Palmer Penguins data (344 penguins, 3 species, Palmer Archipelago, Antarctica), collected by Dr. Kristen Gorman and the Palmer Station LTER. Released under CC0. Source: Horst AM, Hill AP, Gorman KB (2020), palmerpenguins R package; CSV taken from the `palmerpenguins` Python package (MIT).
